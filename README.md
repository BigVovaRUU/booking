# 🦷 Care Dental – Онлайн-запись на приём

Современное веб-приложение для стоматологической клиники **Care Dental**.  
Проект реализует онлайн-запись пациентов с выбором даты и времени, поддержкой **светлой/тёмной темы** и **адаптивным интерфейсом**.

## ✨ Возможности
- 📅 **Интерактивный календарь** с выбором даты.
- ⏰ **Динамические слоты времени** (разные для будней и выходных).
- 🌙 **Поддержка светлой/тёмной темы** (сохраняется в LocalStorage).
- 💾 **Автосохранение формы** (имя, телефон, email, услуга).
- ✅ **Экран успеха** после подтверждения записи.
- 🔔 **Toast уведомления**.
- 📥 **Экспорт в календарь (ICS файл)**.
- 📱 **Адаптивный дизайн** для мобильных и десктопа.
- 🎨 **Современные иконки Heroicons**.

## 🚀 Запуск проекта
1. Склонируй репозиторий:
    ```bash
    git clone https://github.com/username/care-dental.git
    ```

	2.	Перейди в папку проекта:
```bash
cd care-dental
```

	3.	Открой файл index.html в браузере.

⚡ Интернет-соединение требуется для загрузки TailwindCSS и Google Fonts.

🎯 Как пользоваться
	1.	Заполни форму: имя, телефон, email, выбери услугу.
	2.	В календаре выбери дату и подходящий временной слот.
	3.	Нажми кнопку «Подтвердить запись».
	4.	Получи экран подтверждения с деталями записи.
	5.	(Опционально) добавь событие в календарь через ICS файл.
